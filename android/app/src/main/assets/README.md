# ScamShield Assets Directory

Place the generated model artifacts here:

1. `scam_model_quantized.onnx`
   - Generated by `ml/train_and_export.py`
   - Dynamically quantized INT8 model (<35MB)
   
2. `vocab.txt`
   - Hugging Face tokenizer vocabulary exported by `ml/train_and_export.py`

When `ml/train_and_export.py` runs, it automatically outputs both files into `ml/output/android_assets/`. You can copy them here directly:

```bash
cp ml/output/android_assets/* android/app/src/main/assets/
```
